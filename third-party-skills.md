# Third-party skills and plugins

Verified via web research before installation (existence, actual `SKILL.md`/README content, hooks/scripts, licensing). Re-verify at install time — a repo may have moved, been renamed, or changed since.

**Rule**: one install method per item — plugin marketplace *or* manual copy, never both for the same thing. Items where only a slice of a larger repo is wanted use a manual sparse copy, since installing as a plugin would pull in the whole repository.

| Item | Official repo | Install method | Notes from verification |
|---|---|---|---|
| **Superpowers** | [`obra/superpowers`](https://github.com/obra/superpowers) (author Jesse Vincent, independently corroborated) | Plugin marketplace:<br>`claude plugin marketplace add obra/superpowers-marketplace`<br>`claude plugin install superpowers@superpowers-marketplace` | Safe. Ships a `SessionStart` hook that only reads a local markdown file and injects it as context — no network calls, no arbitrary execution. |
| **Caveman** | [`JuliusBrussee/caveman`](https://github.com/JuliusBrussee/caveman) | Manual copy of **only** `skills/caveman/SKILL.md` → `~/.claude/skills/caveman/SKILL.md` (downloaded directly from the raw file to preserve exact content) | The repo has 3 components: skill, Proxy, Middleware. **Only the skill was installed.** The Proxy (license BSL-1.1) has opt-out telemetry by default and stores recoverable data — including potentially secrets — in a local SQLite DB, per its own `SECURITY.md`. Do not install the Proxy or Middleware. The `skills/` folder in the repo also has ~20 other subfolders (caveman-commit, caveman-review, safe-refactor, etc.) that are a much larger agent-harness suite — not part of what was requested; only `skills/caveman/` (the single-file compression rule) was copied. |

## Settings note

The `attribution` key (see `claude/settings.json`) is the current documented way to suppress Claude's commit/PR co-authorship trailers — `includeCoAuthoredBy` is deprecated. There's an open upstream issue (`anthropics/claude-code#65657`) reporting it's sometimes ignored on Windows; always verify with a real test commit after setup (see `SETUP.md` step 3.4).
